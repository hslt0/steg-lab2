# PVG-стеганографія у градаціях сірого

Навчальна програма приховує UTF-8-повідомлення у зображенні за допомогою
повного PVG-методу. Кольорове вхідне зображення автоматично перетворюється
на градації сірого. Це стеганографія, а не криптографічне шифрування:
повідомлення приховується у зображенні, але не шифрується паролем.

## Порівняння зображень до та після приховування

| Вхідне зображення — `pic.png` | Результат — `pic_output.png` |
|---|---|
| <img src="pic.png" alt="Вхідне кольорове зображення пляжу" width="480"> | <img src="pic_output.png" alt="Зображення після перетворення у градації сірого та приховування повідомлення" width="480"> |

Обидва зображення мають розмір **1600 × 800** пікселів. Вхідний файл має
режим **RGBA**, а результат — **L** (8-бітні градації сірого). Після вилучення
з `pic_output.png` отримано повідомлення **`Herasymenko Viktor`**.

Для оцінки змін вхідне зображення порівнювалося з результатом після
перетворення в grayscale:

- змінено **80 із 1 280 000 пікселів** (приблизно **0,00625%**);
- середня абсолютна різниця яскравості становить приблизно **0,00011** за
  шкалою 0–255.

Отже, зміни, внесені під час приховування, майже непомітні. Саме перетворення
кольорового зображення у grayscale змінює його вигляд значно більше, ніж
PVG-кодування. Розмір файлу також змінюється через режим зображення та
стиснення PNG, тому його не слід використовувати як показник візуальної
різниці.

## Запуск

Потрібні Python і Pillow:

```powershell
python -m pip install -r requirements.txt
python main.py
```

У меню:

1. Оберіть **1**, вкажіть вхідне зображення, шлях для результату (наприклад,
   `pic_output.png`) і повідомлення.
2. Оберіть **2**, щоб вказати зображення з прихованим повідомленням і
   прочитати його.
3. Оберіть **0**, щоб вийти.

Зберігайте результат у форматі без втрат: **PNG, BMP або TIFF**. Збереження
у JPEG може пошкодити дані, необхідні для вилучення повідомлення.

## Файли проєкту

- `main.py` — інтерактивне меню.
- `constants.py` — діапазони різниць пікселів і константи PVG.
- `pvg_codec.py` — вбудовування та вилучення байтів методом PVG.
- `image_io.py` — відкриття, перетворення та збереження зображень.
- `requirements.txt` — залежності проєкту.
